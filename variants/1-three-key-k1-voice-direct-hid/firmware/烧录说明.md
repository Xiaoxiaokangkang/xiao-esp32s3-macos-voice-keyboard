# V1 Direct HID Edition / V1 免安装版：固件烧录

推荐运行 `烧录V1-Direct.command`，或用 ESP32-S3 烧录工具将 `XIAO-ESP32S3-Voice-Keyboard-V1-Direct-complete.bin` 写入地址 `0x0`。

如果烧录工具要求分立文件：

- `0x0000` → `bootloader.bin`
- `0x8000` → `partitions.bin`
- `0xE000` → `boot_app0.bin`
- `0x10000` → `firmware-app-V1-Direct.bin`

进入下载模式：按住 `BOOT/B`，短按 `RESET/R`，先松开 RESET，再松开 BOOT。烧录结束后若仍停留在下载模式，只短按一次 RESET。

下载后可在本目录校验文件：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

切换到 V1 Fn Bridge Edition / V1 桥接兼容版时，重新烧录 `../1-three-key-k1-voice/firmware/` 中的 V1 完整固件。
