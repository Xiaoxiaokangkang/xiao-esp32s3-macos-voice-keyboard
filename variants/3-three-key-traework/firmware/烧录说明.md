# V3 固件烧录

推荐运行 `烧录V3.command`，或使用 ESP32-S3 烧录工具将 `XIAO-ESP32S3-Voice-Keyboard-V3-complete.bin` 写入地址 `0x0`。

如果烧录工具要求分立文件：

- `0x0000` → `bootloader.bin`
- `0x8000` → `partitions.bin`
- `0xE000` → `boot_app0.bin`
- `0x10000` → `firmware-app-V3.bin`

烧录成功并重新连接后，USB 产品名应显示为 `XIAO Voice Keyboard V3 TraeWork`。
