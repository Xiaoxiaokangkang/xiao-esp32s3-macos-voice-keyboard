# V2 免安装版固件烧录

推荐运行 `烧录V2.command`，或将 `XIAO-ESP32S3-Voice-Keyboard-V2-complete.bin` 写入 ESP32-S3 的 `0x0`。

该镜像内置 Consumer HID `0x029D`、标准 Keyboard HID 和 USB 麦克风，不需要安装 Fn Bridge 或授予辅助功能权限。烧录后产品名为 `XIAO Voice Keyboard V2 Direct`，VID:PID 为 `2886:0060`。

分立文件地址：

- `0x0000` → `bootloader.bin`
- `0x8000` → `partitions.bin`
- `0xE000` → `boot_app0.bin`
- `0x10000` → `firmware-app-V2.bin`
